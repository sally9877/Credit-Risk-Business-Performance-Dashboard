# Credit Risk & Business Performance Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive **Power BI dashboard** designed to monitor business performance and analyze key financial indicators, including revenue, orders, outstanding balances, and payment behavior.

The dashboard transforms business data into meaningful visual insights to support financial monitoring and data-driven decision-making.

## 🎯 Project Objectives

- Monitor overall revenue and order performance.
- Analyze cash sales and outstanding balances.
- Understand revenue distribution by payment method.
- Compare cash and installment sales across business channels.
- Analyze outstanding balances by aging bucket.
- Track monthly trends in total orders and outstanding amounts.

## 📌 Key Performance Indicators (KPIs)

- Total Revenue
- Total Orders
- Total Outstanding
- Cash Sales
- Average Order Value (AOV)

## 📈 Dashboard Visualizations

- Cash vs. Installments by Business Channel
- Revenue by Payment Method
- Outstanding Amount by Aging Bucket
- Monthly Trends: Total Orders and Total Outstanding

## 🎛️ Interactive Features

Interactive slicers allow users to filter and analyze data by:

- Sales Platform
- Agent Name
- Payment Method
- Business Channel
- Aging Bucket

## 🛠️ Tools & Skills

- Microsoft Power BI
- Data Analysis
- Data Visualization
- KPI Monitoring
- Interactive Dashboard Design
- Business Performance Analysis

## 💡 Key Takeaway

This project demonstrates how Power BI can transform business data into an interactive dashboard that makes financial performance easier to monitor, trends easier to explore, and business insights easier to communicate.
